# Source code used in the paper "Loss-based multi-objective design optimization framework for hybrid bracing frames with partially self-centering capacity" for Loss Prediction

Usage:
1. Install the required packages using ```uv venv``` and ```uv sync``` commands.
2. Run train1.py for the first stage of training.
3. Run train2.py for the second stage of training.
4. Run get_shap_figures for generating SHAP figures.
